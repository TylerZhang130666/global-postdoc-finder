# 首轮搜索：五项简版资料

直接填写或用自然语言回答；已有CV可让助手提取，不必重复填完整模板。

1. **研究方向与主要方法**：研究什么？会哪些实验、模型、软件或分析方法？可附一项代表性成果。
2. **毕业与入职时间**：预计何时完成博士？这里指答辩、完成要求还是拿到学位？最早何时可以入职？不确定就写“不确定”。
3. **优先地区**：按顺序写国家/地区，也可写“全球、无地区偏好”；注明排除地点。
4. **目标机会**：正式招聘、个人博士后基金、潜在接收导师，或几类都看。
5. **必要条件**：例如必须有签证支持、最低合同期限；没有就写“暂无”。偏好与不可接受条件分开写。

例如：

```text
研究方向与方法：水环境，现场采样、R统计分析、GIS；想继续做环境数据研究。
毕业与入职：预计明年完成博士，学位授予月份待确认；完成后可入职。
优先地区：日本、新加坡，同等优先；暂不扩展。
目标机会：正式招聘为主，也看需要接收导师的基金。
必要条件：需要国际申请人可进入的申请路线；其他暂无。
```

这足以开始首轮。遇到具体岗位后，再按要求补问语言证明、流动性、提名或学位时间等；没有证据保持“待核实”。单条招聘核验无需先填这五项，只有判断个人匹配时才需要背景。

姓名、私人邮箱、电话、证件和完整生日不是检索必需信息。需要进一步梳理时再使用[详细画像模板](candidate-profile-template.md)。
