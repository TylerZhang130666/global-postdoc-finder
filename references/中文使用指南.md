# 全球博士后搜索 Skill 中文使用指南

## 核心原则

搜索范围和优先级由用户决定，skill 不会默认欧洲、美国、名校或任何地区优先。

- 用户说“德国、荷兰优先，加拿大其次”，就先完成德国和荷兰，再搜索加拿大。
- 用户说“只看新加坡和澳大利亚”，就不推荐其他国家。
- 用户说“全球都可以”，才按全球各地区分批搜索。
- 用户没有说明地区时，应先询问地区偏好，而不是自行决定。
- 用户列出多个国家但没有排序时，按同等优先级处理。

## 建议提供的信息

使用者可以上传CV，也可以直接说明：

- 研究方向和主要方法
- 已发表论文、项目、软件或其他成果
- 预计毕业或可入职时间
- 第一优先国家、地区、城市或机构
- 第二优先地区
- 明确排除的地区
- 希望申请正式岗位、个人基金，还是两者都看
- 是否要求签证支持、最低合同期限或最低薪酬

姓名、邮箱、电话、家庭住址、证件号码等不是搜索所必需的信息，可以删除或遮盖。

## 可直接复制的提示词

### 指定优先顺序

```text
使用 $global-postdoc-finder，根据我的CV寻找博士后。

第一优先：德国、荷兰
第二优先：加拿大、新加坡
排除：美国
预计入职时间：2027年7月以后
只保留对国际申请人开放的机会。
请分别列出公开招聘岗位、博士后基金和潜在导师，并提供官方链接、截止日期、匹配度、信息可信度和下一步行动。
```

### 只搜索指定国家

```text
使用 $global-postdoc-finder，只搜索日本和新加坡的博士后机会，不要扩展到其他国家。根据我的研究方向生成当地常用的英文、日文岗位关键词，并优先查询官方招聘网站。
```

### 全球搜索

```text
使用 $global-postdoc-finder 做一次全球博士后搜索。我没有地区偏好，但要求岗位对国际申请人开放，合同至少两年。请按地区分组，再按研究匹配度排序。
```

## 三类结果的区别

- **岗位与招聘线索**：分别标注已核实在招、滚动招聘、过期和状态未确认；线索不能直接当作可投岗位。
- **博士后基金**：需要候选人和导师申请的资助，不等于已经获得岗位。
- **潜在导师或团队**：研究方向匹配，但目前未确认有空缺，适合关注或联系。

## 如何看优先级和评分

结果先按用户指定的地区层级排列，再在同一层级内部按匹配度排序：

- 数值匹配分档：A为75分及以上，B为55分至不足75分，C为不足55分。
- 行动A：高分、来源和当前入口已核实，必需资格与入职条件均有支持。
- 行动B：值得核实或准备，包括高分但关键资格未知，或后续轮次尚未开放。
- 行动C：低匹配、来源冲突/不明、入口关闭或邀请未确认。
- Excluded：确认存在资格冲突或岗位已过期，先排除再评分。
- Host only：潜在导师/团队，仅表示可研究或联系，不等于有岗位。

CV中没有写某项语言、国籍或居留记录，表示未知，不能据此认定不符合。基金要区分新申请、提名和受邀阶段，不能把未来的第二阶段截止日当作第一阶段仍开放。具体规则见[筛选与评分说明](screening-and-scoring.md)。

高排名不代表保证录取；评分必须由岗位原文和候选人真实经历支持。
