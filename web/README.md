# 博后搜索

[在线使用](https://tylerzhang130666.github.io/global-postdoc-finder/)

网页直接搜索已收录岗位，按地区、来源和截止时间筛选，查看详情、一键收藏。参考招聘网站的搜索栏、结果列表和侧边详情结构，保留白底、简单排版。无需模型 API、注册或安装依赖。

## 招聘数据

`scripts/sync_jobs.py` 同步 13 个公开招聘列表：

| 来源 | 本版范围 |
| --- | --- |
| AcademicTransfer | postdoc 关键词，首屏 10 条；后续动态分页 API 禁止采集，未覆盖全部结果 |
| 香港大学 | 博后类别，最多五页；只保留含博后名称的标题 |
| CSIRO | postdoctoral 关键词，最多两页 |
| 耶鲁大学 | Open Positions，最多四十页；排除单独的 postgraduate 职位 |
| 斯坦福大学 | 公开博后列表，最多两页；保留院系、导师与原始详情链接 |
| 莱布尼茨协会、马克斯普朗克学会 | 可读公开列表中的明确博后标题；马普继续读取 Show more 分页 |
| ETH Zürich | 全部可见岗位；按地点区分瑞士、新加坡，未知留空 |
| 哥本哈根大学、KTH | 招聘表中的明确博后标题，保留完整截止日期 |
| UBC | 博后招聘表，境外招聘不一律归为加拿大 |
| JREC-IN | 研究员/博后类目，按实际分页控件读取最多六页，只保留明确博后标题 |
| jobs.ac.uk | 博后分类的实际“Next”分页；未知工作地点不一律归为英国 |

这是有限来源的岗位索引，不声称完整覆盖全球。只收录来源列表中实际出现的字段；未知截止日期留空。摘要为来源列表短摘录，不生成申请资格或匹配分。收录时间不等于招聘状态或个人资格核验时间。

采集器遵守公开 robots 规则和访问间隔，不使用登录、绕过验证或代理。只跟随同域分页，按原链接去重。有来源失败时保留其旧记录和原收录日期，页面注明“上次记录”；来源说明显示部分更新。无法识别的 HTML 视为失败，不当作零岗位。

GitHub Actions 每小时第 23 分钟（UTC）尝试刷新并部署；调度可能延迟。定时任务会先读取本站上次发布的缓存，读取失败才回退仓库快照。刷新不需要写回 GitHub 仓库或新凭据。标准 Ubuntu 运行器、公开仓库和 GitHub Pages 沿用免费方案，不配置模型 API 或付费后端；发布 artifact 仅保留一天。

页面的“刷新”通过禁用缓存的请求读取最新已发布索引，保留当前关键词与筛选；它不会触发实时全网采集。维护者可通过“数据来源 → 维护者手动采集”进入 GitHub Actions，点击 Run workflow；采集和部署完成后再刷新页面。页面与各来源显示实际收录时间，旧缓存不会变成新的核验日期。

## 搜索与收藏

- 直接在索引中检索标题、机构、院系与短摘要；关键词按空格交集匹配。少量中文方向词对应英文词，例如“遥感”“机器学习”，不使用语义模型。
- 全部 13 个来源均启用公告正文词项索引。核对具体公告标题后，按各站正文区域提取工作内容、要求和条件；JREC 跟随公告自带的官方英文切换。不发布完整招聘正文或联系人信息。正文命中标注“匹配公告正文”；“数据来源”逐站显示已索引、待读取和暂不可读数量。
- 正文成功缓存一天，失败六小时后重试，各来源有独立读取预算。刷新失败保留上次成功词项和日期，待索引或不可读的公告仍可检索列表字段。仓库中的较新正文证据不会被较新的列表快照抹掉。
- [2026-11-18 漏收与漏检审计](../examples/search-audit-2026-11-18/README.md)：同一批 380 条记录、28 组词对比正文索引前后，同时另计列表补收。全文词项命中不等于研究方向匹配，正文中的通用申请说明也可能命中。
- 零结果提示只说明当前库没有匹配，显示所选地区的收录数量，不声称当地没有岗位。“清除关键词”保留地区，只有主动点“查看其他地区”才扩大地区范围。空结果时隐藏空白详情框。
- 默认隐藏截止已过的记录，已注明时区的时刻按该时区计算；未注明截止时间的记录继续显示，是否招聘以原公告为准。
- 保留原站 `global-postdoc-finder:workbench:v1` 本地存储与 JSON 格式，旧收藏仍可编辑。搜索结果一键收藏不自动填写人工核验日期或确认资格。
- 收藏只在当前浏览器保存，可导出 JSON 备份或 CSV 查看；支持导入 Skill 的规范化记录。换浏览器、清除网站数据前请先备份。

## 开发

```sh
python scripts/sync_jobs.py
node --test web/tests/*.test.mjs
python -m unittest discover -s tests -v
python -m http.server 8769 --bind localhost --directory web
```

打开 http://localhost:8769 。Windows 沙箱不允许测试启动子进程时，可使用 `node --test --test-isolation=none web/tests/core.test.mjs web/tests/jobs.test.mjs`。

`.github/workflows/pages.yml` 在 PR 中运行离线测试；推送 `main`、手动运行或定时触发时，同步公开岗位后发布 GitHub Pages。发布物只包含页面、模块、图标、公开来源和岗位索引，不包含测试、试用候选人或个人 CV。
